# Recover E2 Self-Recovery

Date: October 30, 2026.

## Correction

Recover E2 now has one shared implementation for every class. The final E2
dispatcher routes Recover to that implementation; nine obsolete/class-specific
branches were removed rather than retained as competing resolutions.

Recover drops itself, then its generic Deadzone cost offers a real card or a
Shell. The activating player then chooses one actual card from the resulting
Drop. Recover itself is eligible.
If it is the only Drop card, the picker still opens and the player selects it
and confirms. Other eligible cards remain selectable when present.

Recover E1's End Phase timing, existing empty-Deadzone cost accounting and
phase-boundary defeat checks are unchanged.

## Verification

- 190 empty-zone cases: 19 classes, both standard seats, and all four seats in
  Tag and Team. The picker contains only Recover, belongs to the activating
  player, and choosing Recover moves that exact card to hand.
- 40 populated-zone cases check manual Deadzone payment, self-selection, and
  selection of a different, non-first Drop card for Restorative and Shadow.
- Two queued Casualty Draw cases check that recovering itself resumes the next
  draw and its normal Continue prompt without leaving the queue busy.
- Existing eight reported-effect groups and the counterattack/Cease suite pass.
- Real Chromium tests display the sole Recover option and use actual card and
  Confirm clicks for Restorative and Shadow. These are constructed browser
  positions, not full natural games.

Reproduce:

```powershell
node tools/headless/recover-e2-regressions.js
node tools/headless/counter-cease-regressions.js
node tools/recover-e2-browser.js
```

The browser test needs Playwright and a configured Chromium executable.
